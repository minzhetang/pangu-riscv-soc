## 实际用途与真实执行链

低速设备动作异常时，需要知道“先错了哪个动作、等了多久、故障前后发生了什么”，而不只是看到报警灯。原型由未改SM2 CPU/SoC执行真正编译的裸机C，通过同步GPIO及timer读取状态，过滤、顺序/等待规则、RAM环形记录，批次完成后物理UART输出。KEY1/2/3明确模拟设备输入，没有部署到真实工业设备。

固定规则0→1→3→7→0，采样2700000目标tick/128次，WAIT20、2连续样本稳定过滤、8槽事件记录。首次故障后保留2条后续变化再冻结，之后变化显式拒绝；环满显式evicted，调度过载reason3冻结，不静默补采。采集中不打印，结束后导出，导出期间不采集。没有RX/中断/外部传感器/Flash日志。CPU、存储时序、外设接口及约束不因本轮补验而改。
