# 历史引用与精简规则

本包围绕当前作品源码和必要输入组织，未复制全部历史运行。各阶段原SHA256SUMS/FINAL_MANIFEST/COPY_IDENTITY/AUDIT/COMMANDS是其原交付时的记录，可能指向原A工作区、原VVP/DB/位流或未携带的大轨迹。它们用于来源/版本解释，不是本包完整性检查入口，也不能直接据其旧PASS判断当前任意重建。

已保留：全部主要RTL/软件/TB/参考/冻结输入、763例计划、核心有限结果、候选前后代表反例、应用完整板级字节、片上四WDF/CSV、Cache/AI有限原记录。未保留：无用VVP/EXE/缓存、PDS实现DB/ADF/生成网表、sbit/SVF、M5多数完整WB/STORE长文本、M6压缩长流、大N234 RX波形、重复历史日志。

因此：

- 各历史audit.py/VERIFY_PACKAGE.py可能明确要求未携带的原清单全部文件或A的89/208保护项，不能把它们直接作为本包验收入口；只运行新根CHECK_STATIC可核当前材料。
- M5参考与TB完整，复验可在新副本重新执行同一镜像/冻结规则生成实际流并逐笔比较；本包不据省略的全流宣称本轮新重放通过。
- M6源码保留积压守卫误计归档gzip的已知缺陷，D330已决定不重跑，不能因包里有controller.py就启动旧长跑。
- 原B离线工具保留G1–G3未闭项，比较/ABI的有限证明不能替代其资源守卫验收。
- DBG-O2的FIC指向需要合法重新生成的预综合网表；原四个WDF真实样本可离线读取，不能冒新采集。

真正缺少的不是当前主线源代码，而是某些复验需要由复验者合法取得的工具/模型、重新生成的输出或全量历史数据。为避免巨包，本包没有承诺“一条命令重做全部历史”；准确入口和最短检查路径见REPRODUCIBILITY。
