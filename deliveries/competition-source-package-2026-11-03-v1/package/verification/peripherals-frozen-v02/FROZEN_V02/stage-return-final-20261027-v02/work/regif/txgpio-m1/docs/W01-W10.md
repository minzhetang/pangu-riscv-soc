## 关键写语义

- 请求：pre-edge `rst_n && io_sel && io_wr_en`
- 成功：`addr[1:0]==00`、`io_wstrb==1111`，且 `addr==0x00` 时 `tx_ready==1`，或 `addr==0x0c`
- 其它请求：`io_wr_error=1`，不触发 TX/GPIO 写
- TX/GPIO 高 24 位忽略；GPIO 固定 8 位
- 读：00→0、08→tx_ready、0c→gpio_out、10→gpio_in_sync；未选中/非对齐/保留→0；无副作用
