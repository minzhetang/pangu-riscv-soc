正常模式每沿推进；同步模式首有效沿phase0等待、随后交替推进/等待。暂停沿所有流水寄存/PC/EEI/RF写回保持；存储写可在phase0发生一次，推进沿不得重复。真实物理周期单列；raw stall/flush高电平两拍不是两个架构事件。六程序每例预期逻辑stall/flush沿用原值；C/CRC逻辑计数沿用原参考，默认周期与原基线对照，同步物理周期按先冻结推进模型解释。
